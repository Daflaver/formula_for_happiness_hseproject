## О проекте

В социологии уровень счастья — интегральный, субъективный показатель. В эпоху цифровизации соцсети становятся «зеркалом» эмоционального и социального состояния человека.

**Цель проекта:** разработать комплексную математическую метрику на основе многомерного анализа социальной активности пользователей ВКонтакте и доказать эффективность методов Deep Learning для оценки эмоционального фона контента.

**ML-задача:** трёхклассовая классификация тональности текста (`негативный / позитивный / нейтральный`).

**Задачи:**
- Сбор выборки пользователей (100–200+) через VK API с сегментацией по возрасту (18–35 лет) и географии (крупные города РФ).
- Предобработка: очистка текстов, фильтрация выбросов и ботов.
- ML-эксперимент: сравнение классического ML (TF-IDF + линейные модели) и DL-подходов (RuBERT) на задаче анализа тональности, в том числе при доменном сдвиге (отзывы -> соцсети).
- Формирование и обоснование весовых коэффициентов формулы Индекса счастья.
- Сегментированный анализ (по полу, возрасту) и визуализация результатов.
- Интерактивное Gradio-приложение для сравнения моделей и расчёта индекса по произвольному тексту.

Подробное техническое задание и обоснование архитектурных решений — в файле [`Проект Формула счастья диздок.pdf`](./Проект%20Формула%20счастья%20диздок.pdf).

## Формула индекса счастья

$$\text{Happiness\_Index} = 0.30 \cdot S_{\text{network}} + 0.20 \cdot S_{\text{activity}} + 0.50 \cdot S_{\text{sentiment}}$$

| Компонент | Признак | Вес | Обоснование |
|---|---|---|---|
| $S_{\text{network}}$ | нормированное (log + Min-Max) число друзей, с отсечением выбросов через квантили | **0.30** | социальные связи коррелируют с субъективным благополучием |
| $S_{\text{activity}}$ | нормированная сумма собственных постов + репостов | **0.20** | вовлечённость в платформу как показатель социальной активности |
| $S_{\text{sentiment}}$ | доля позитивно окрашенного авторского контента (по предсказаниям DL-модели) | **0.50** | ключевой показатель — эмоциональный фон контента |

Все компоненты приводятся к шкале **[0, 1]**.

### Штрафные корректировки

После расчёта базового индекса применяются дополнительные штрафы:

| Штраф | Условие | Эффект |
|---|---|---|
| **Токсичность** | наличие депрессивных/токсичных сообществ среди подписок (по ключевым словам в описании) | `× 0.85` |
| **Эффект витрины / коммерция** | коэффициент взаимности `friends / (followers + 1) < 0.2` (подписчиков в 5+ раз больше друзей — типично для блогера/витрины) | `× 0.90` |
| **Индекс бессонницы** | доля постов, опубликованных в 01:00–05:00 | линейный вычет до `-0.15` |

Итоговый индекс округляется и клипуется в `[0, 1]`, после чего размечается на уровни:

- **Высокий** — `≥ 0.65`
- **Средний** — `0.40–0.65`
- **Низкий** — `< 0.40`

## Данные

Проект использует **два датасета**:

| # | Датасет | Источник | Размер | Описание |
|---|---|---|---|---|
| 1 | `data.zip` (→ `data.json`) | VK API (собственный сбор) | ~743 профиля | пользователи 18–35 лет, 7 крупных городов РФ |
| 2 | [`k1tub/sentiment_dataset`](https://huggingface.co/datasets/k1tub/sentiment_dataset) | HuggingFace Datasets | 290 458 текстов | русскоязычный корпус тональности (отзывы, комментарии, посты): `0` — негатив, `1` — позитив, `2` — нейтрально |

### Формат `data.json` (внутри `data.zip`)

Распакуйте `data.zip` — внутри лежит `data.json`: список профилей, каждый — словарь вида:

```json
{
  "id": "230173495",
  "city": "Москва",
  "age": 33,
  "gender": "female",
  "photos_num": 0,
  "videos_num": 0,
  "audio_num": 0,
  "followers_num": 0,
  "posts": {
    "<post_id>": { "text": "...", "date": "21.05.2019 16:39:09" }
  },
  "groups": {
    "<group_id>": { "name": "...", "description": "..." }
  }
}
```

> `data.zip` лежит в корне репозитория (`main`). Скрипт сбора данных `dataset_collector.py`, которым он был сформирован — там же.

3. Выполните ячейки по порядку — первая ячейка ставит зависимости (`!pip install ...`).
4. Дойдя до раздела 10, получите рассчитанный `happiness_index` для каждого пользователя; в разделе 11 — визуализации по сегментам.

```bash
jupyter notebook gradio_app.ipynb
```

При запуске приложение:

Если ни одна модель не найдена, приложение сообщит об этом — соответствующих моделей просто не будет в выпадающем списке (см. раздел [«Папка `artifacts/`»](#структура-репозитория)).

## Gradio-приложение

`gradio_app.ipynb` — приложение с двумя вкладками:

1. **Сравнение моделей** — вводите текст поста, и все доступные модели (TF-IDF+LogReg/LinearSVC, RuBERT default/Optuna, xLSTM, Classic BiLSTM) показывают свой прогноз тональности и уверенность.
2. **Калькулятор индекса счастья** — рассчитывает `HI = 0.30·Сеть + 0.20·Активность + 0.50·Тональность` со штрафами за токсичные сообщества, «витринный» аккаунт и ночную активность — на основе введённых данных или текста.

Модели подгружаются динамически: какие артефакты найдены в `artifacts/`, такие модели и появятся в выпадающем списке, отсортированные по weighted F1.

## Результаты ML/DL-экспериментов

| Модель | Целевой домен | Weighted F1 | Примечание |
|---|---|---|---|
| TF-IDF + LogReg | Отзывы/новости (in-domain) | **0.619** | классика побеждает на привычном домене |
| TF-IDF + NB | Отзывы/новости (in-domain) | 0.613 | сопоставимо с LogReg |
| RuBERT (zero-shot) | Отзывы/новости (cross-domain) | 0.404 | трансформер без дообучения уступает |
| **TF-IDF + LogReg** | **Соцсети (cross-domain)** | **0.323** | деградация при доменном сдвиге |
| **RuBERT (zero-shot)** | **Соцсети (cross-domain)** | **0.442** | устойчивость к доменному сдвигу — выбрана для финального пайплайна |

**Главный вывод:** классический ML, переобученный на словах-маркерах из отзывов, теряет почти половину предсказательной силы при переносе на неформальные тексты соцсетей. RuBERT обобщает лучше, поэтому именно его предсказания легли в основу формулы Индекса счастья.

## Ограничения модели

1. **Эффект «витрины социальных сетей»** — пользователи склонны транслировать «успешный успех» и маскировать негативные эмоции. Метрика оценивает *цифровое поведение*, а не реальное психологическое состояние.
2. **Проблема иронии и сарказма** — модель плохо различает ярко-позитивные слова, использованные в ироничном/негативном контексте.
3. **Эвристические веса** — коэффициенты формулы ($\alpha_1=0.3$, $\alpha_2=0.2$, $\alpha_3=0.5$) заданы на основе социологических паттернов, без математической оптимизации по функции потерь.

## Этический протокол

- **Открытость:** данные собираются только из публичных профилей (`is_closed: False`).
- **Приватность:** личные сообщения, закрытые фото и скрытые списки друзей не запрашиваются и не анализируются.
- **Деперсонализация:** в датасете (`data.json` внутри `data.zip`) и аналитике пользователи фигурируют как обезличенные ID; ФИО не используются при расчёте метрик.
